# 🛰️ Roadmap Técnico — Bryan Cucho Suyo
### Ingeniero en Telecomunicaciones → Pre-Sales Engineer / Solution Architect / Platform Engineer

Este vault es tu **mapa de progresión técnica** durante el ciclo de Ingeniero en Télécom Paris (filières **GIN + MODS**, 2026–2028), pensado para producir evidencia real (proyectos + certificaciones) que respalde tu candidatura a roles de **Pre-Sales Engineer**, **Solution Architect** o **Platform Engineer**.

Está diseñado para usarse en **Obsidian** (checkboxes, enlaces `[[ ]]`, tags) y para vivir como **README de un repo GitHub** (`bryan-telecom-roadmap`) que sirva de portafolio público.

## Cómo usar este vault

1. Abre esta carpeta como vault en Obsidian (`Abrir carpeta como vault`).
2. Marca las casillas `- [ ]` a medida que avances — Obsidian las trackea automáticamente.
3. Sube la carpeta completa a un repo GitHub llamado por ejemplo `telecom-portfolio-roadmap`. El `README.md` de la raíz (este archivo) se renderiza directo en GitHub.
4. Cada proyecto del portafolio (sección 3) debería vivir en su **propio repo** — enlaza aquí solo el nombre y el link una vez creado.
5. Revisa este roadmap **cada fin de periodo académico** (P1–P4) y ajusta fechas reales vs. planeadas.

## Tu punto de partida (contexto usado para este plan)

- Egresado de Ing. Telecomunicaciones (UNI, Perú). Práctica en preventa Huawei (videoconferencia, propuestas técnico-comerciales, nube privada) + soporte de servidores CDN para retransmisión IPTV.
- Inicias 2do año de Télécom Paris con **GIN** (Grandes Infrastructures Numériques: redes IP, cloud, seguridad, redes móviles/IoT, CDN, multimedia) + **MODS** (Marchés, Organisations, Données, Stratégies: lectura estratégica/económica, gestión de proyectos, innovación).
- Esta combinación es exactamente el perfil que Télécom Paris asocia a **"architecte / ingénieur avant-vente"**: profundidad técnica de infraestructuras + capacidad de discutir valor, costo y estrategia. Tu roadmap de certificaciones y proyectos debe reforzar ambos lados a la vez, no solo el técnico.
- Idiomas: inglés C1, francés B1 — suficientes para certificaciones internacionales y para operar en el mercado francés/europeo (referencia útil dado que Télécom Paris tiene partners como **OVHcloud, Datadog, STMicroelectronics**).

## Principio guía del plan

No coleccionar certificaciones sueltas. Cada certificación existe para **destrabar o legitimar un proyecto de portafolio**, y cada proyecto existe para **demostrar en código/arquitectura lo que un curso de GIN/MODS te dio en teoría**. El objetivo final (3A, 2027–2028) es tener 1 repo "hub" con 5-6 proyectos sólidos + 4-6 certificaciones activas, listo para procesos de reclutamiento de Solutions/Presales/Platform Engineering en Francia o internacional.
